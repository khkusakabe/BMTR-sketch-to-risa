# Model Generator (Sketch2Frame) – UI mockups

Static HTML mockups for the NCSEA Hackathon Model Generator.

| Page | File |
|---|---|
| Projects home | `index.html` |
| New Project | `new-project.html` |

No build step. Open `index.html` in a browser, or serve the folder from any static host.

## Publish with GitHub Pages
1. Commit these files to the repo root (or a `/docs` folder).
2. Repo **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, pick `main` and `/ (root)` or `/docs`.
3. The site appears at `https://<user-or-org>.github.io/<repo>/`.

## Notes
- Project rows and the Create Project / design-criteria buttons are placeholders (`href="#"`) for the next screens.
- Rows marked "Example" are demo data.
