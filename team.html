The idea

Engineers start a lot of models from a marked-up PDF or a quick sketch, then retype every node and member into RISA. This app lets you trace the drawing instead, or have it find the lines for you, and export a starting RISA-3D model. Everything runs in the browser and nothing is uploaded.

Try it in a minute

  1. Download prototype/samples/hand-sketch.jpg (a two-bay, two-story braced frame drawn like a phone photo) and open it in the app.
  2. Set scale: click the bottoms of the first two columns and type 25'.
  3. Find lines: click once on the drawing. Seven dashed suggestions appear.
  4. Delete the long ground line, then Accept. You get 9 nodes and 11 connected members.
  5. Supports: click the three column bases.
  6. Export: copy the Nodes, Members and Boundary Conditions rows into RISA-3D, or download the DXF.

Snap to nodes and members, Shift for ortho, a live length readout, undo.

Auto-detects straight members in clean drawings and sketch photos, joins corners and T's, adds nodes at crossings.

Pinned, Fixed and Roller, drawn on the model.
doneExport
Tab-separated rows for the RISA spreadsheets, DXF (feet, layer MEMBERS), CSV, and save/load of the project.

The model

Nodes are stored in drawing pixels: {id, x, y, support}. Members are {id, i, j}, node ids. One number, ftPerPx, turns pixels into feet on export. The origin is the lowest, leftmost node. Elevation exports X and Y (Y up), and plan exports X and Z.

Line detection pipeline

  1. Adaptive threshold (Bradley and Roth, 2007): ink is anything clearly darker than its surroundings, which copes with uneven photo lighting.
  2. Thinning (Zhang and Suen, 1984): strokes of any width become 1 px center lines.
  3. Hough transform (Duda and Hart, 1972): take the strongest straight line, split its ink into continuous runs, keep long dense runs, remove their votes, repeat.
  4. Cleanup: merge broken pieces of one line, square up lines within 3 degrees of level or plumb, extend or trim ends to meet at corners and T's.

A sketch photo at 1600 x 1200 runs in about 0.2 seconds. The slider sets the shortest line to keep, which filters out text and hatching.

How to work on it

  1. Get access: send Kei your GitHub username and you'll get a collaborator invite.
  2. Clone and run: 
    git clone https://github.com/khkusakabe/BMTR-sketch-to-risa.git
cd BMTR-sketch-to-risa
python -m http.server 8080
    Then open http://localhost:8080. Any static server works.
  3. Branch per task: git switch -c grid-snap, commit small, and open a pull request. main is the live site, so keep it working.
  4. Keep it plain: no build step, so anyone can open the files and go. If you add a library, load a pinned version from cdnjs.

Known limits

  • Find lines only does straight lines. Arcs and curved members are not detected.
  • Dimension lines, ground lines and borders get found too. Box the framing or delete the extras.
  • Export assumes feet. Units and member properties get set in RISA.

This tool helps an engineer build a starting model faster. The engineer checks every coordinate, connection and support in RISA and owns the design.
